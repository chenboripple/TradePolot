# experiments/ — 一次性研究脚本归档

本目录存放项目演进过程中的**一次性研究/调参/联调脚本**（2026-09-06 从仓库根目录迁入）。
它们不是产品代码：无测试覆盖、不参与 CI、不保证当前还能跑通。

## 重要口径提示

这里大量脚本产出的"高收益"结论（如 `optimize_*`、`research_*`、`backtest_000868*`）
基于研究期口径，存在系统性偏差，**不可作为实盘预期**：

- 前视撮合：信号当日收盘价成交（统一引擎为次日开盘撮合）；
- 成本低估：未计或低计佣金、印花税、滑点，无涨跌停拦截；
- 样本内寻优：参数在同一段历史上挑选并汇报，无样本外验证；
- 窗口选择偏差：只展示表现好的区间（同一标的换窗口可从 +49% 变 -49.9%）。

当前唯一可信口径：Web「回测记录」/ `tradepilot backtest`（统一撮合引擎）
与 walk-forward 样本外验证。详见根目录 `BACKTEST_SUMMARY.md` 等报告顶部的可信度提示。

## 重新运行

多数脚本假定 CWD 为仓库根目录；部分用 `__file__` 相对路径找 `src/`，迁移后需改用：

```bash
PYTHONPATH=src python3 experiments/<script>.py
```

数据依赖（本地日线停在 2026-04-17、tushare token、MX_APIKEY）与迁移时一致，未做更新。
